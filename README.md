# Маленькая вселенная ♡

Нежный интерактивный сайт-подарок: коробочка, 12 планет с комплиментами и финальный экран для фотографии.

## Как запустить на компьютере

1. Установи Node.js (версия 18 или новее): https://nodejs.org/
2. Распакуй архив.
3. Открой терминал в папке проекта и выполни:

   ```bash
   npm install
   npm run dev
   ```

4. Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Как добавить фотографию позже

Положи фотографию в папку `public` и назови файл **photo.jpg**.
Финальный экран автоматически покажет её вместо заглушки. Подойдут JPG/JPEG; если фотография PNG, переименуй её в `photo.jpg` только после конвертации в JPG.

## Как изменить комплименты

Открой `src/main.jsx`. В начале файла есть массив `compliments`.
У каждой планеты есть `name`, `title` и `text` — можно заменить их на ваши личные фразы. Сейчас там стоят примерные комплименты.

## Публикация на GitHub Pages

Проект собран с относительным `base: './'`, поэтому его можно размещать в репозитории GitHub Pages в подпапке. Для сборки выполни:

```bash
npm install
npm run build
```

Готовый сайт появится в папке `dist`. Для автоматической публикации можно добавить GitHub Actions workflow для Vite/GitHub Pages.
